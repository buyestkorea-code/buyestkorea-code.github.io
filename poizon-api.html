연결 현황

가격 정책

사이트 판매가를 현재 환율로 달러로 바꾼 값이 기준가입니다(정수 달러). 입찰가는 기준가에서 하한(−%)~상한(+%) 안에서만 정해집니다. POIZON은 기준가보다 너무 높으면 거부하므로(8월 시험에서 2배부터 거부) 상한은 +50%를 권해요.

연결 확인이 필요한 상품

자동으로 확정하지 않고 사람이 봐야 하는 상품이에요. 브랜드가 다름(사이트와 POIZON 브랜드 불일치), 색상이 다름(상품명 색상과 POIZON 색상이 다른 계열), 상품 여럿(같은 품번에 POIZON 상품이 여러 개이고 색상으로도 못 정함), 품번 일부 일치(색상 코드를 뺀 품번으로만 맞음)입니다. 확정 전에는 입찰 대상이 되지 않아요.

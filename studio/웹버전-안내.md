# BUYEST 릴스 만들기 (studio/)

사진 + 프롬프트 → Higgsfield(Seedance)가 릴스 영상을 만들고, 이 화면이 한글 훅·자막·가격을 얹어 MP4로 완성합니다. 설치 없음, 열 때마다 최신.

## 구성
- `index.html` — 화면 한 장 (사진 → 프롬프트 → 글자 얹기 → 비용 확인 → 만들기). 로그인은 툴키트 인트라넷 로그인(localStorage `buyest.dash.auth`)을 그대로 확인
- `engine.js` — 캔버스로 AI 영상 위에 글자를 그려 H.264 MP4 로 인코딩 (WebCodecs + mp4-muxer). AI 영상의 소리는 AAC 로 다시 인코딩해 그대로 붙임. 1080×1920, 30fps, 인스타 안전영역 안에만 글자
- `vendor/mp4-muxer.js` — mp4-muxer 5.1.3 (MIT)
- 서버: 저장소 `reels-worker/` (Cloudflare Worker `buyest-reels`) — 배포·키 등록은 그 폴더 README
- 결과 보관: 브라우저 IndexedDB 7일·12개 (다른 PC 에서는 안 보임). 사용 금액 기록: localStorage `buyest.reels.spend` (이 브라우저에서 쓴 예상 합계, 실제 잔액은 Higgsfield 콘솔)

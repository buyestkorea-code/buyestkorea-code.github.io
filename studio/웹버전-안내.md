# BUYEST 영상 스튜디오 — 웹 버전 (v2.0.0)

PC 설치 없이 이 페이지(`studio/`)에서 브라우저 안에서 영상을 만든다. 서버·설치·업데이트 버튼 없음. 열 때마다 최신.

## 구조
- `index.html` — 화면(⓪ 기획·대본 / ① 상품 릴스 / ② 템플릿 영상 / ③ 기획 영상 요청서 / 내가 만든 영상). 로그인은 툴키트 인트라넷 로그인(localStorage `buyest.dash.auth`)을 그대로 확인 (pos.html 과 같은 방식, 화면 잠금일 뿐 서버 인증 아님)
- `engine.js` — 캔버스로 한 프레임씩 그림 → WebCodecs(H.264) 인코딩 → mp4-muxer 로 MP4. 1080×1920, 30fps, 인스타 안전영역(위 230 / 1440 아래 / 오른쪽 230) 안에만 글자
- `planner.js` — ⓪ 기획·대본 (v1.1.0 그대로 + 영상 스타일 10종)
- `vendor/mp4-muxer.js` — mp4-muxer 5.1.3 (MIT, npm 원본 그대로)
- 결과 보관: 브라우저 IndexedDB 7일·12개 (다른 PC에서는 안 보임)

## 새 템플릿 추가
`engine.js` 의 `TEMPLATES` 배열에 `{ id, name, duration, slots[], texts[], draw(ctx, t, S) }` 한 개 추가하면 ② 탭에 자동으로 나온다. 글자는 `drawCaption()` (자막 모양 5종: 기본 박스·종이컷·VHS·형광펜·미니멀) 을 쓰면 안전영역·자막 모양 선택이 같이 적용된다.

## 옛 PC 설치형과 달라진 점
- Remotion·HyperFrames·OpenMontage 를 더 이상 쓰지 않는다 (Remotion 유료 라이선스 문제도 사라짐). ① 은 같은 모양을 캔버스로 다시 그린 것
- ② 는 임의 HTML 대신 템플릿 3종(촬영본+자막 / 키즈 신상 / 정보형 콜라주) + 문구·시간 수정 방식
- ③ OpenMontage(AGPL, AI 에이전트 실행)는 웹에서 돌릴 수 없어 "요청서 만들기"로 대체
- 옛 설치형(`buyest-video-studio-v1.x.zip`, `latest.json`, install 파일)은 이미 설치한 PC용으로 저장소에 남겨 둠. 지우려면 사용자 확인 후

# BUYEST 자동 제작 스튜디오 — Codex 테스트 버전

사진 → AI 기획 → 장면별 AI 영상 → 한국어 내레이션 → 타이밍 자막 → MP4.
같은 기획에서 1080×1350 카드뉴스 PNG와 ZIP도 출력합니다.

## 실행

Node 24 이상, FFmpeg(ASS/libass와 H.264 포함)가 필요합니다.

```powershell
cd studio-server
npm ci
Copy-Item .env.example .env # 최초 한 번만, 기존 .env는 덮어쓰지 말 것
npm start
```

http://127.0.0.1:4317/studio-next/ 에서 사용합니다.
`start-local.ps1`은 서버를 숨김 창으로 실행합니다. 이미 실행 중이면 해당 주소를 안내합니다.
종료하려면 `.runtime/server.pid`에 기록된 PID를 확인한 뒤 해당 Node 프로세스만 종료하세요.

## 실제 AI 연결

서버 `.env`에 키를 저장하고 서버를 다시 시작합니다. 키는 브라우저로 전달하지 않으며 Git에서 제외됩니다.

| 설정 | 용도 |
|---|---|
| GEMINI_API_KEY / GEMINI_MODEL | 사진 분석·대본·장면 프롬프트·카드 카피 |
| HF_API_KEY | Higgsfield 사진 업로드·장면 생성. 공식 KEY_ID:KEY_SECRET 형식 |
| ELEVENLABS_API_KEY / ELEVENLABS_VOICE_ID | 한국어 음성. 계정에서 사용할 수 있는 음성 ID |
| CREATOMATE_API_KEY (선택) | 설정하면 실제 릴스 최종 합성에 Creatomate 사용 |
| STUDIO_MUSIC_PATH (선택) | 사용 권한이 있는 로컬 음원 절대 경로. 미설정 시 배경음악 없음 |

기본 합성은 로컬 FFmpeg입니다. Creatomate 사용 시에도 장면 정규화에는 FFmpeg가 필요합니다.
현재 사용 계정의 모델·voice 가용성과 가격은 키 연결 후 실제 소량 생성으로 검증해야 합니다.
Gemini 설정 기본값은 검토 당시 공식 문서의 예시이며 계정에서 사용 가능한 모델로 변경할 수 있습니다.

## 흐름

1. 릴스 / 카드뉴스 / 둘 다를 선택합니다.
2. 최대 8장의 사진과 선택적인 상품 정보를 넣습니다.
3. 자동 만들기를 누르면 사진 분석과 구조화 기획을 생성합니다.
4. 릴스는 AI 영상 예상 비용과 한도를 확인한 후 생성합니다. 기획·음성·클라우드 렌더 요금은 별도이며 영상 한도는 전체 서비스 요금 상한이 아닙니다.
5. 장면별 음성과 타이밍을 만들고 그 길이에 맞춰 영상 생성·편집을 진행합니다.
6. 완성본은 내 작업에서 다시 열거나 다운로드합니다.

카드뉴스만 선택하면 TTS와 영상 API는 호출하지 않습니다.
동일 상품 다각도와 서로 다른 상품은 장면의 사진 참조로 구분합니다.
확인되지 않은 가격·소재 등을 작성하지 않도록 지시하고 결과 형식·사진 범위를 검증합니다. 사실 정확성은 최종 검수가 필요합니다.

## 저장·재시도

사진·기획·영상 ID·결과는 `.data/<project-id>/`에 저장합니다.
서버가 켜져 있으면 브라우저를 닫아도 생성이 계속됩니다.
서버 재시작 시 중단된 작업을 표시하고 내 작업에서 재시도합니다. 완료한 음성·장면을 재사용합니다.
Higgsfield에는 프로젝트·장면별 고정 멱등 키를 보냅니다. 실패한 외부 작업은 해당 콘솔에서 원인을 확인해야 하며 무조건 새 유료 요청을 만들지 않습니다.
Creatomate 제출 결과가 불확실하면 자동 재제출하지 않습니다. 콘솔에서 결과를 확인한 뒤 서버의 cloud-render.json에 확인된 ID로 복구해야 합니다.

## 샘플의 의미

‘샘플로 테스트’는 서버가 만든 상품 일러스트에 고정 기획·카메라 모션·자막을 합성합니다.
AI 기획, AI 영상, 음성을 실제로 생성하지 않습니다. 화면·영상·카드에 샘플임을 표시합니다.
무료 샘플의 성공은 실제 AI 품질 검증을 의미하지 않습니다.

## 테스트

```powershell
npm test
npm run test:coverage
```

검증 범위: 기획 검증, 실제 타임스탬프 자막, 예산 검증, 재시도 재사용, 외부 요청 계약(모의 응답), 서버 재시작, 실제 FFmpeg MP4, PNG·ZIP 출력.
외부 유료 API를 실제 호출하는 테스트는 포함하지 않습니다. 증거는 `docs/studio-tdd.md`를 참고하세요.

## 배포 전

현재 서버는 127.0.0.1에만 바인딩된 개인 PC 테스트용입니다. GitHub Pages는 이 Node 서버를 실행하지 않습니다.
공유 운영에는 별도 서버 배포, 기존 직원 세션 검증, 직원별 프로젝트 권한, 객체 저장소, 동시 작업 제한, 보관·삭제 정책이 필요합니다.
기존 `studio/`와 배포 사이트는 교체하지 않았습니다.

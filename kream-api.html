크림 API TEST

크림 최저가가 우리가 정한 할인 한도보다 더 낮은 상품만 모아서 보여 줍니다. 상품마다 가격을 정하고 내려받으면, 그 파일로 크림에 가격을 반영합니다.
차이(%)는 (크림 최저가 ÷ 우리 판매가 − 1) 입니다. 표시 순서는 차이가 큰 것부터입니다.

검토 목록(review_queue.csv)을 여기에 놓거나 아래 버튼으로 선택하세요 가격 동기화 프로그램(kream_sync.py)이 만든 파일입니다. 이미 결정을 채운 파일도 다시 열 수 있어요.
한 번에 정하기
차이가 % 이내인 건은 크림 최저가에 맞춤 그보다 더 낮은 건은 직접 확인합니다.
품번 · 사이즈수량우리 판매가크림 최저가차이 결정새 가격
조건에 맞는 줄이 없어요. 구간이나 검색어를 바꿔 보세요.
줄을 선택하면 한 번에 정할 수 있어요.

가격은 천원 단위, 최소 20,000원으로 반영됩니다. 결정 파일을 내려받은 뒤 kream_sync.py --stock 재고.csv --decisions 결정파일.csv --apply 로 크림에 보냅니다. 서버 연동 후에는 이 화면의 승인 버튼으로 바로 전송할 예정입니다.

우리 판매가에서 몇 %까지 내려 팔지, 최저가가 그보다 더 낮을 때 어떻게 할지 정합니다. 값을 바꾸면 아래 계산기에서 바로 결과를 볼 수 있어요.

허용 최저선 = 판매가 × (1 − 최대 할인율), 천원 단위로 올림. 가격은 최소 20,000원, 천원 단위입니다.

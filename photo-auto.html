사진 자동화 TEST

사진 + 기본틀 엑셀 + 상품명만 넣으면 상세페이지 이미지(폭 720px)를 자동으로 조립합니다. 실측은 직접 입력하세요. 전부 이 브라우저 안에서 처리되며 서버로 올라가지 않습니다.

① 상품명

폴더 이름과 같은 형식: 브랜드(한글) 시즌 … 색상 품번. 입력하면 아래 항목이 자동으로 채워집니다.

② 파일

기본틀 엑셀(.xlsx)을 끌어놓거나 클릭
상품 사진(여러 장)을 끌어놓거나 클릭
파일명 순서대로 정렬 · 첫 사진이 메인

③ 상세 정보 (자동으로 채운 값 — 틀리면 고쳐 쓰세요)

    ✏ 만든 뒤에는 미리보기의 글자를 눌러 바로 고칠 수 있습니다(Enter=적용, Esc=취소). 다시 '만들기'를 누르면 미리보기에서 직접 고친 글자(표·고정문구)는 초기화되고, 위 입력칸 값은 유지됩니다. PSD의 글자 레이어를 보려면 PC에 Pretendard 글꼴(Light·Regular·Bold)이 설치돼 있어야 합니다.
